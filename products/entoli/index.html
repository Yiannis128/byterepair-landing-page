Entoli (εντολή) is the Greek word for a command, both the one you give and the one the agent runs.

Skills & Agents · Artifacts · Planning Mode · Group Chat · Sandboxing & Safe Autonomy · Bring Any Model · Byte Repair Inside · Everywhere You Work

Entoli is a general-purpose, open-source agent. Give it a task, not just a question: it loads the skills it needs, runs tools on your machine, researches on the web, edits files, and hands back something you can open and use, not a wall of text. Below: the features that make it one, and how they fit together.

Skills & Agents

Entoli gets things done through skills: capability packages the agent picks up when a task calls for them. Research, writing, file handling, running shell commands on your machine, editing code, or reading the pages you send it to with the integrated browser: you can pick a skill yourself or let the agent load what it needs, and every skill’s commands still execute on your hardware, within the reach you gave it, sandboxed.

Need a capability Entoli does not ship with? Install skills from the marketplace: the library of community skills is one click away.

Artifacts

Ask for a dashboard, a map, an interactive report, a calculator, and Entoli builds it as an artifact: a page published to the built-in viewer, summarised in the chat, explorable and yours to keep. The carousel above shows it live: a task goes in, an explorable Drake-equation visualisation with a galaxy map comes out. Deliverables, not documentation.

Planning Mode

For work too big for one prompt, Entoli plans before it acts. The agent writes out the steps, you review and adjust the plan, and nothing runs until you approve it. Watch the agent work through what you signed off, step by step. You stay the editor-in-chief of everything it does.

Group Chat

Some tasks split naturally. Put several agents in one conversation: a coder, a researcher, a reviewer, or roles of your own. They collaborate in the open, mention an agent and the work routes to it, while you watch the whole exchange and steer. One assistant, a whole team.

Sandboxing & Safe Autonomy

Speed needs a safety net. Every command an agent runs goes through sandboxing, so its actions touch only what you allowed, and an auto-mode classifier reads each step before it executes, judging whether it is safe to run without asking you. Risky work stops for your approval; routine work flows. Autonomy with a conscience.

Bring Any Model

Entoli ships no model; it connects to yours. Point it at Ollama (local or Ollama Cloud), OpenAI, Anthropic, Google, Z.AI, OpenRouter, or Groq, and any OpenAI-compatible or Anthropic-style endpoint. Run a local model and the assistant runs entirely on-device, including audio transcription and speech synthesis: usable offline, and your voice never leaves the machine. Your keys, your endpoints, your hardware. There is no server of ours in the middle.

Byte Repair Inside

For code, Entoli has a layer no other agentic harness ships: Byte Repair, formal verification inside the coding loop. LLM-generated code has a habit of the classic vulnerabilities: memory leaks, overflow/underflow, array bounds failures. Byte Repair encodes the program as a mathematically constrained model, proves them out, and routes each finding back through the agent for an automatic fix that is re-verified against the same proof. You code like any other agentic assistant; the math checks underneath.

Everywhere You Work

The same assistant runs on Windows, macOS, and Linux desktop, on Android and iOS, and on the web. Use source-control sync to carry your work between devices and make the agent keep pace with your day.
